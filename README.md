# أم ملاك — Oum Malak
موقع عربي RTL لعرض إبداعات الخياطة، بتصميم متجاوب وشاشة افتتاحية Splash Screen ولوحة إدارة محمية بـ Supabase Auth + RLS.

## تشغيل
افتح index.html عبر خادم محلي (مثل `python -m http.server`). الواجهة تعرض **صورًا توضيحية فقط** حتى يتم ربط المشروع. استبدل الصور بمنتجات أم ملاك الحقيقية قبل الإعلان عن الموقع.

## Supabase
1. أنشئ مشروع Supabase مخصصًا للموقع؛ لا تستخدم مشروعًا آخر دون قصد.
2. نفّذ `supabase/schema.sql` في SQL Editor بمشروع الموقع بعد مراجعة السياسات.
3. أنشئ حساب مستخدم للوالدة في Auth > Users، ثم أضف UUID إلى `om_malak_admins` بواسطة SQL Editor.
4. املأ `config.json` بعنوان المشروع و**publishable key فقط** (مفتاح عام، وليس service_role/secret)، وأضف رقم واتساب دوليًا من دون +.
5. لا تضع أي كلمة مرور أو service_role أو secret key في GitHub أو في كود المتصفح.
6. تفعيل GitHub Pages: Settings > Pages > Source = GitHub Actions. الرابط المتوقع: https://marccuell839-collab.github.io/win-tools/

## ملاحظات
- الصور التوضيحية مصدرها Unsplash وليست منتجات حقيقية.
- عند عدم ضبط Supabase أو رقم واتساب، تبقى الواجهة عرضًا تجريبيًا بلا استقبال طلبات.
- إدارة المنتجات تعمل فقط بعد ضبط Auth وجدول المسؤولين وسياسات RLS.
- حذف المنتج لا يحذف الصورة القديمة من التخزين؛ يمكن إضافة تنظيف التخزين لاحقًا.
